## Detailed Breakdown of Remaining Areas for Improvement

### 1. Re-routing `"pruned_timeline"` and `"pruned_conlang"` in `cli_handlers.py` and `registry_specs/`

In an earlier release ([ADR-0001](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/docs/adr/0001-demotion-of-normative-evaluators-and-three-subsystems.md)), the prescriptive versions of `timeline` and `conlang` were demoted and mapped in [`scripts/lib/cli_handlers.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/cli_handlers.py) (`DISPATCH_TABLE`) to `"pruned_timeline"` and `"pruned_conlang"`, which print deprecation notices. Even though commit [`fbf2ed7`](https://github.com/aryansinghnagar/Ars-Arcanum/commit/fbf2ed77053f13c535137e912ea0eb2cc39b7ad8) added the deterministic replacements ([`timeline_solver.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/timeline_solver.py) and [`conlang_linter.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/conlang_linter.py)), running `python scripts/arcanum timeline` or `python scripts/arcanum conlang` still hits the pruned notice in `DISPATCH_TABLE`.
* **Fix**: Update `DISPATCH_TABLE` in [`scripts/lib/cli_handlers.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/cli_handlers.py) and the domain catalogs in [`scripts/lib/registry_specs/`](https://github.com/aryansinghnagar/Ars-Arcanum/tree/main/scripts/lib/registry_specs) so `timeline`, `conlang`, `epistemic`, `ledger`, `braid`, and `effort` are first-class subcommands with dedicated `main(argv)` CLI parsers.

### 2. Completing the "Strangler Fig" Cutover Inside Legacy Modules

Right now, the codebase is in a classic mid-migration state where both old and new implementations coexist:
* [`scripts/lib/frontmatter.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/frontmatter.py) and [`scripts/lib/vault_index.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/vault_index.py) both define `parse_frontmatter()`, meaning existing callers that import `from lib.frontmatter import parse_frontmatter` still miss out on multiline YAML block scalars (`|` and `>`).
* [`scripts/lib/manuscript_diff.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/manuscript_diff.py) and [`scripts/lib/revision_heatmap.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/revision_heatmap.py) still run their internal $O(N^2)$ `SequenceMatcher` loops until their diff functions delegate to `compare_chapter_hierarchical()` in [`scripts/lib/diff_core.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/diff_core.py).
* [`scripts/lib/docx_sync.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/docx_sync.py) and [`scripts/lib/docx_builder.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/docx_builder.py) need their `sync pull` and `export` handlers wired to `pull_docx_to_markdown()` and `export_markdown_to_docx()` in [`scripts/lib/docx_tracked_changes.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/docx_tracked_changes.py).
* [`scripts/lib/registry.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/registry.py) still loads `.arcanum/plugins/*.py` via `spec_from_file_location` unless its plugin execution method calls `run_plugin_sandboxed()` from [`scripts/lib/plugin_sandbox.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/plugin_sandbox.py).

### 3. Vault Auto-Loader Bridge for File-Driven Continuity Audits

While [`epistemic_firewall.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/epistemic_firewall.py), [`timeline_solver.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/timeline_solver.py), [`conlang_linter.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/conlang_linter.py), and [`resource_ledger.py`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/resource_ledger.py) implement clean, pure-function engines over dataclasses, authors running the CLI against a live vault directory (`~/Universes/Reliquary/` or `~/Manuscripts/Prisoner-of-Sand-Sea/`) need an automatic vault parser that reads `world.yaml`, `Characters/*.md`, `Locations/*.md`, `Languages/*.pgd`, and `Book-01/Draft-01/**/*.md` via [`VaultIndex`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/scripts/lib/vault_index.py) and feeds the resulting dataclasses into all four continuity engines automatically.

### 4. Aligning `pyproject.toml`, `mypy.ini`, and `.github/workflows/ci.yml`

* **In [`pyproject.toml`](https://github.com/aryansinghnagar/Ars-Arcanum/blob/main/pyproject.toml)**: Update `[tool.setuptools.packages.find]` so both `scripts*` and `src/arcanum*` are packaged, and add `src/arcanum` to `[tool.coverage.run] source`.
